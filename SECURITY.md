# Security Policy

## Authorized use

Run these notebooks only with synthetic data, in an isolated lab, or against systems you own and are explicitly authorized to test. Do not direct scanners, traffic generators, credential demonstrations, or reconnaissance utilities at third-party services without written permission.

## Sensitive data

Do not commit API keys, tokens, passwords, private keys, packet captures, production logs, personal data, or proprietary datasets. Use environment variables or Google Colab secrets for credentials.

## Reporting a problem

If you find an exposed credential, unsafe default, or unintended destructive behavior, report it privately to the repository owner. Do not include working secrets or sensitive evidence in a public issue.
